# 🌐 Personal Developer Portfolio

Welcome to the source code for my personal developer portfolio website! This project showcases my featured software projects, technical skills, and work experience.

## ✨ Features
* **Responsive UI:** Optimized for desktop, tablet, and mobile browsers.
* **Project Showcase:** Highlights key applications including my Fitness application and AI Research Assistant.
* **Containerized Deployment:** Packaged with Docker for fast, portable deployment anywhere.

## 🛠️ Built With
* **Frontend:** HTML5, CSS3, JavaScript
* **Containerization:** Docker (Nginx)

## 🐳 Docker Hub
* **Docker Hub Image:** [sandeep2026paswan/my-portfolio](https://docker.com)

### Quick Start with Docker
Pull and run the pre-built container image locally:

```bash
docker run -d -p 8080:80 --name my-portfolio sandeep2026paswan/my-portfolio:latest
```

Once running, open your browser and visit **`http://localhost:8080`**.

## 💻 Running Locally from Source
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Open the project:** Navigate into the `My-Portfolio` folder and open `index.html` in your browser (or launch it with VS Code Live Server).
